# 🚀 Featured Project

## Blaniko — Experience Discovery & Outing Planning Platform

Blaniko is a software platform designed to help users decide **what to do and where to go** by combining reliable venue information with personalized experience recommendations.

Unlike traditional directories, Blaniko focuses on:
- Structured and reliable activity/venue data
- Explainable recommendation logic
- User-oriented discovery experiences
- Building a foundation for scalable experience-based applications

**My role:**
- Founder
- Software Engineering Lead
- Product and technical decision making
- Full-stack development
